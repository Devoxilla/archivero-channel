# Google Flow clips: EP002-pearl-harbor

11 short video clips for the key moments. Each one replaces a still picture in the video.

**In Google Flow** (labs.google/flow, with your Gemini plan):
1. New project. Choose **Text to Video**, model **Veo** (Fast is fine), landscape **16:9**, 1 output.
2. Paste one prompt below and generate. If a still picture for that shot already exists, you can use **Frames to Video** instead and give it that picture as the first frame, with the same prompt.
3. Download the clip (720p or 1080p) and rename it to the name above its prompt, e.g. `S06_a.mp4`.
4. Upload the clips in the chat with Claude (or to `episodes/EP002-pearl-harbor/art/` on GitHub). The next build plays them; the voice-over replaces their sound.
